# Homelancer Digital: two-system starter

Open `project.godot` in Godot 4.3 or newer and run. This is an isolated original-content prototype. It needs no Freelancer data and uses no LibreLancer source or assets.

W/S move; A/D turn; Shift boost; Space shoot. Fly near the gray hub and press F to dock. Docking repairs hull; U buys a weapon upgrade with 10 credits earned by destroying the orange drone. R launches. Fly near the blue beacon and hold T for 1.5 seconds to move between System A and System B. You can return through the beacon in System B. Planets and asteroids are untextured placeholders.

Current scope: local single player. The multiplayer test described in the research report is separate throwaway code and is not integrated here. Persistence, missions, mobile touch controls, browser export, coordinated multiplayer crossings, and capacity testing remain to be built. Godot is unavailable in the present environment, so runtime behavior has not been verified.
