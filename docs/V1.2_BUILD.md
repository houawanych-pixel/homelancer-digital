# Homelancer Digital v1.2 — build notes

## What was reviewed
- Repository `houawanych-pixel/homelancer-digital`: `main` (starter), `build01-mobile-combat` (commits 873c7e3,
  96c53b2, 827f4eb). The Build 02 script drew its HUD with `_draw()` on a `Node3D`, which Godot does not allow, so
  it never ran. v1.2 keeps its concepts (Solara/Vega, New Terra, Liberty Hub, Eden Prime, Frontier Exchange, Aquila
  and Solara gates, Cadet/Ranger/Lancer, 5 repairs, missiles, auto/manual fire) and rebuilds them as proper screens.
- Google Drive: Homelancer Master Game + Galaxy Bible, Engine & Multiplayer Research (partial), Unity Cadet PRD and
  the Unity Cadet folder, which holds the only ship models found.

Identity comes from the file names, which are unambiguous. The source files are over the 10 MB limit of the Drive
connector used for this build, so they are not yet in the repository. Until they are, each role uses an original
low-poly stand-in built in `scripts/ships.gd`, and the game says so.

**To add them:** optimise each GLB for phones (target under ~3 MB and under ~30k triangles, textures 1024 px), save
with the slot file name above, and commit. `ShipFactory` loads them automatically, scales each once to its target
length (Cadet 9 m, enemy 10 m, fleet 16 m), centres the pivot and faces it along -Z. If a model imports facing the
wrong way, set the third value (extra yaw degrees) for that key in `ShipFactory.GLB`.

## Design
- Two systems with different layouts, star colour, sky and hazards. Solara: Liberty Hub, New Terra, Solara Belt
  (rock), Violet Reach nebula, Aquila Jump Gate. Vega: Frontier Exchange, Eden Prime, Vega Ice Field, Azure Veil
  nebula, Solara Jump Gate.
- Flight: arcade 6-DOF with yaw/pitch, visual banking, inertia, strafe, CRUISE engines (5× speed after a 1.6 s
  charge, cancelled by firing or damage) and GO TO / SET COURSE autopilot to any station, planet or gate.
- Combat: travelling laser bolts with aim assist to the lead point, AUTO fire when a hostile is inside the reticle
  cone, homing missiles, regenerating shields (after 3 s without damage), 5 repair kits (+40 % hull each), target
  brackets, lead marker, target health, off-screen arrow, radar. Enemies make attack runs and peel off.
- Economy: kills pay 150 (raider) / 220 (corsair) credits. Weapons 600–2600 cr, missiles 40 cr, Ranger 1500,
  Lancer 4000. Purchases change real stats (damage, fire rate, hull, shield, speed, turn, guns, missile rack).
- Docking: DOCK appears within range of a station bay or a planet's landing beacon, then a short autopilot docking
  sequence and fade into the hub. Docking repairs and resupplies for free. Launch reverses it.
- Jump gates: JUMP appears near the gate; controls lock, the ship aligns and flies through the ring, warp tunnel,
  new system loads, ship exits at the destination gate, controls return.
- Asteroids: 150–160 rocks per field in 3 instanced draw calls, with collision (bounce + damage) and bolt blocking.
- Nebulae: 26 soft cloud sprites, coloured haze while inside, radar range cut to 40 %.
- Defeat: the ship is towed to the local station (10 % salvage fee) instead of a game over.

## Performance choices
Compatibility renderer, no real-time shadows, one directional light, instanced asteroids, shared materials,
generated textures at 384 px or less, capped sprite counts. Real-GPU frame rate on a Samsung phone is not yet measured.

## Known issues / not yet done
- Real ship GLBs not yet imported (see above).
- Frame rate only measured under software rendering in the test container (about 5 fps with no GPU), which
  says nothing about a real phone. Real-device testing is still needed.
- Hub interiors are illustrated 2D scenes, not modelled rooms.
- No save between browser sessions (credits persist for the play session only, as specified).
- No sound yet.
