# Homelancer Digital v1.2 — build notes

## What was reviewed
- Repository `houawanych-pixel/homelancer-digital`: `main` (starter), `build01-mobile-combat` (commits 873c7e3,
  96c53b2, 827f4eb). The Build 02 script drew its HUD with `_draw()` on a `Node3D`, which Godot does not allow, so
  it never ran. v1.2 keeps its concepts (Solara/Vega, New Terra, Liberty Hub, Eden Prime, Frontier Exchange, Aquila
  and Solara gates, Cadet/Ranger/Lancer, 5 repairs, missiles, auto/manual fire) and rebuilds them as proper screens.
- Google Drive: Homelancer Master Game + Galaxy Bible, Engine & Multiplayer Research (partial), Unity Cadet PRD and
  the Unity Cadet folder, which holds the only ship models found.

Made with `tools/shipkit` (see its README): cut out, nose → -Z with the detailed side up, front third narrowed
(tip width 65 % cargo / 70 % carrier / 80 % enemy), meshoptimizer reduction, textures 512–1024 px stored as
lossy WebP. Whole web download (`index.pck`) is 2.1 MB; phone-landscape load 4.7 s in the test container.
**Player ship and weapons (2026-09-30):** from the high-detail fighter sheet (`24f1fb07…glb`: one fighter + 22
weapon pieces). Fighter → `assets/ships/player/cadet_ship.glb` (277,658 → 34,110 triangles, 2.0 MB — near-identical
to the source in close-up renders). White missile → `assets/weapons/missile.glb` (1,216 tris, used for every fired
missile, with an engine glow). Spiked sphere → `assets/weapons/mine.glb` (576 tris, used for deployed mines).
Budgets raised after owner feedback that the first pass looked choppy: enemy 6,142, cargo 9,728, carrier 38,208.
Enemy and cargo stay soft because their source sheets are low detail; replacing them with high-detail sources
like the fighter sheet is the fix. `tools/shipkit/studio.sh` renders any GLB in-engine for checking.
Web download (`index.pck`) is now 6.2 MB.

**Lancer gunship (2026-09-30):** owner's spaceship conversion `cb220928…glb` (gunship + gatling + missile pod +
three small craft, which were discarded). Repairs with `tools/shipkit/shipfix.py`: tinted glass shell inside the open
chin-gunner cage, both open side bay doors removed, both open side bays closed with weathered hull plating, landing
gear removed (belly left intact). 288k → 19,187 triangles, 1.5 MB → `assets/ships/player/lancer.glb` (the Lancer
at the ship dealer). Gatling gun and missile pod saved as `assets/weapons/gatling.glb` / `rocket_pod.glb`
(registered in `ShipFactory`, not yet shown in flight).

## Known issues / not yet done
- Player Cadet ship GLB not yet imported (see above); cargo, enemy and carrier are real models.
- Frame rate only measured under software rendering in the test container (about 5 fps with no GPU), which
  says nothing about a real phone. Real-device testing is still needed.
- Hub interiors are illustrated 2D scenes, not modelled rooms.
- No save between browser sessions (credits persist for the play session only, as specified).
- No sound yet.

## Space station model (replaces the primitive station)
`assets/stations/station.glb` — owner's station model (`6f456158…glb`, 484k tris) reduced to 43,978 tris, 2048 px
textures (lossy WebP import). Used for every station (Liberty Hub, Frontier Exchange) via `ShipFactory` key
`station`, scaled to 150 units tall; its round docking port faces +Z where the old bay was, and the green guide
lights are kept. If the file is missing the old primitive station is built instead. Adds about 3.6 MB to the web pck.
Route test: RESULT 36/36 PASS. `HL_SHOT_DIR=/path` makes the desktop route test save its screenshots as PNGs.
